# Introduction

Easily design forms in minutes using the popular [React Hook Form](https://react-hook-form.com/)
library alongside [Material-UI](https://v5.mui.com/material-ui/getting-started/).

This package offers a suite of **15 reusable and customizable components**,
reducing code duplication and providing the flexibility to style form fields
according to your website's design.

You can also find additional components in this package, such as **color picker** and **rich text editor**,
that are not currently part of Material UI but can be useful when you need them. More components will be
added based on community feedback. Feel free to raise a feature request or report a bug by contacting
the author of this package.

## Installation

To get started, install the following packages:
- [react-hook-form](https://www.npmjs.com/package/react-hook-form) `v7`
- [@mui/material](https://www.npmjs.com/package/@mui/material) `v6`
- [@mui/icons-material](https://www.npmjs.com/package/@mui/icons-material) `v6`
- [@nish1896/rhf-mui-components](https://www.npmjs.com/package/@nish1896/rhf-mui-components) `v1.0.3`

<PackageManagerTabs

You can refer to the [Material UI installation guide](https://v5.mui.com/material-ui/getting-started/installation/)
for installation instructions.

For date pickers, follow the [installation guide](https://v6.mui.com/x/react-date-pickers/getting-started/)
to install [@mui/x-date-pickers](https://www.npmjs.com/package/@mui/x-date-pickers).

**Optional**: If you are using a third party library for form validation, say
[joi](https://www.npmjs.com/package/joi), make sure to install its npm package along
with the [@hookform/resolvers](https://www.npmjs.com/package/@hookform/resolvers) package.
