# MUISelect

`MUISelect` wraps the Material UI [Select](https://v7.mui.com/material-ui/react-select/) with label, error and helper-text handling. It supports single or multiple selection and either primitive or object options via `labelKey`/`valueKey`.

<Callout type="tip">
  If the number of options **exceeds 20**, consider using [MUIAutocomplete](autocomplete)
  or [MUIMultiAutocomplete](multi-autocomplete) for better searchability, improved keyboard
  navigation, and overall performance.
</Callout>

## Usage

```tsx
import MUISelect, { MUISelectProps } from '@nish1896/mui-components/mui/select';
```

```tsx
const [role, setRole] = useState();

<MUISelect
  fieldName="role"
  options={['Admin', 'Editor', 'Viewer']}
  value={role}
  onValueChange={({ newValue }) => setRole(newValue)}
/>
```

For options as an array of objects:

```jsx
<MUISelect
  fieldName="country"
  options={[
    { code: 'AUS', country: 'Australia' },
    { code: 'IN', country: 'India' },
    { code: 'UAE', country: 'United Arab Emirates' },
  ]}
  labelKey="country"
  valueKey="code"
  multiple
/>
```

<Callout type="warning">
  When using an array of objects for options, both `labelKey` and `valueKey` 
  are required. If either is missing, an error will be thrown.
</Callout>
