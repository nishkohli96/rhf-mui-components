# RHFNumberInput

<AvailabilityBanner componentName="RHFNumberInput" version="2.1" />

**RHFNumberInput** is an enhanced version of the [TextField](https://v7.mui.com/material-ui/react-text-field/)
component that accepts only **integer** or **float** values. It retains
the core functionality, styling options, and flexibility of the TextField,
while seamlessly integrating with react-hook-form for number-specific input handling.

## Usage

```tsx
import RHFNumberInput, { RHFNumberInputProps } from '@nish1896/rhf-mui-components/mui/number-input';
```

To render a fully functional `RHFNumberInput`, you only need two or three essential props.

```tsx
<RHFNumberInput
  fieldName="age"
  control={control}
/>
```
