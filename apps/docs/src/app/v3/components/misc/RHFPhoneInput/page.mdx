# RHFPhoneInput

<AvailabilityBanner componentName="RHFPhoneInput" version="2.0" />

The **RHFPhoneInput** component is built on top of [react-international-phone](https://www.npmjs.com/package/react-international-phone),
a React library for handling international phone numbers.

It integrates seamlessly with Material UI by leveraging the [TextField](https://v7.mui.com/material-ui/react-text-field/)
component together with the [usePhoneInput](https://react-international-phone.vercel.app/docs/Advanced%20Usage/usePhoneInput)
hook from `react-international-phone`, allowing users to select a country and enter phone numbers
in the appropriate international format.

## Usage

```tsx
import RHFPhoneInput, { RHFPhoneInputProps } from '@nish1896/rhf-mui-components/misc/phone-input';
```

```tsx
<RHFPhoneInput
  fieldName="contactNumber"
  control={control}
  value={getValues("contactNumber")}
  phoneInputProps={{
    defaultCountry: "in",
    preferredCountries: ["in", "us", "au"]
  }}
  errorMessage={errors?.contactNumber?.message}
/>
```

The returned phone value after input is of the type -
- "+91 99887-76655"
- "+1 (765) 232-3423"

<Callout type="note">
For field validation, make sure to set the minimum length to atleast **6**.
</Callout>
