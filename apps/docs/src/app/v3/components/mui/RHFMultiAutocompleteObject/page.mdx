# MUIMultiAutocompleteObject

`MUIMultiAutocompleteObject` is a multi-select [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/) with checkboxes and
an optional "**Select All**" row that stores an array of **complete option objects**.

## Usage

```tsx
import MUIMultiAutocompleteObject, {
  MUIMultiAutocompleteObjectProps
} from '@nish1896/mui-components/mui/multi-autocomplete-object';
```

```tsx
const [members, setMembers] = useState<User[]>([]);

<MUIMultiAutocompleteObject
  fieldName="members"
  options={users}
  labelKey="name"
  valueKey="id"
  value={members}
  onValueChange={({ newValue }) => setMembers(newValue)}
/>
```

## Props

`labelKey` and `valueKey` are required. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
