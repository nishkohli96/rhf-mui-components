# RHFTextField

Text fields are a core component of any form, allowing users to input text into the UI.
The **RHFTextField** component extends the functionality of [TextField](https://v7.mui.com/material-ui/react-text-field/),
accepting almost all TextField props while providing additional customization options.

## Usage

```tsx
import RHFTextField, { RHFTextFieldProps } from '@nish1896/rhf-mui-components/mui/textfield';
```

To render a fully functional `RHFTextField`, you only need 3-4 essential props.

```tsx
<RHFTextField
  fieldName="firstName"
  control={control}
  errorMessage={errors?.firstName?.message}
/>
```
