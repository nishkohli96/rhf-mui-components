# MUIRadioGroup

`MUIRadioGroup` wraps the Material UI [RadioGroup](https://v7.mui.com/material-ui/react-radio-button/) for a single choice among `options`, storing the selected value. Supports primitive or object options via `labelKey`/`valueKey`.

## Usage

```tsx
import MUIRadioGroup, { MUIRadioGroupProps } from '@nish1896/mui-components/mui/radio-group';
```

```tsx
const [plan, setPlan] = useState();

<MUIRadioGroup
  fieldName="plan"
  options={['Free', 'Pro', 'Enterprise']}
  value={plan}
  onValueChange={({ newValue }) => setPlan(newValue)}
/>
```

Example with an array of objects:

```jsx
<MUIRadioGroup
  fieldName="nationality"
  options={[
    { code: 'AUS', country: 'Australia' },
    { code: 'IN', country: 'India' },
    { code: 'USA', country: 'United States of America' }
    { code: 'UAE', country: 'United Arab Emirates' }
  ]}
  labelKey="country"
  valueKey="code"
  value={nationality}
/>
```

## Props

For object options, pass `labelKey` and `valueKey`. Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
