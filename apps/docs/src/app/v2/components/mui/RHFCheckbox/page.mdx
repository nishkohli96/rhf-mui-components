# MUICheckbox

`MUICheckbox` is a single [Checkbox](https://v7.mui.com/material-ui/react-checkbox/)
with a boolean value, an inline label, and optional helper text or error state.

## Usage

```tsx
import MUICheckbox, { MUICheckboxProps } from '@nish1896/mui-components/mui/checkbox';
```

```tsx
const [accepted, setAccepted] = useState(false);

<MUICheckbox
  fieldName="terms"
  value={accepted}
  onValueChange={({ newValue }) => setAccepted(newValue)}
  label="I accept the terms and conditions"
/>
```
