# RHFDateTimePicker

**RHFDateTimePicker** extends [DateTimePicker](https://v7.mui.com/x/react-date-pickers/date-time-picker/)
component, allowing users to select the date and time for an event.

## Usage

```tsx
import RHFDateTimePicker, { RHFDateTimePickerProps } from '@nish1896/rhf-mui-components/mui-pickers/date-time';
```

```tsx
<RHFDateTimePicker
  fieldName="meetingDateTime"
  control={control}
  errorMessage={errors?.meetingDateTime?.message}
/>
```
