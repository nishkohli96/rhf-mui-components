# RHFDatePicker

**RHFDatePicker** extends the [DatePicker](https://v7.mui.com/x/react-date-pickers/date-picker/)
component to let users select a date and can be customized in a similar way.

## Usage

```tsx
import RHFDatePicker, { RHFDatePickerProps } from '@nish1896/rhf-mui-components/mui-pickers/date';
```

```tsx
<RHFDatePicker
  fieldName="dateOfBirth"
  control={control}
  errorMessage={errors?.dateOfBirth?.message}
/>
```

## API
`RHFDatePickerProps` extends [DatePickerProps](https://v7.mui.com/x/api/date-pickers/date-picker/)
