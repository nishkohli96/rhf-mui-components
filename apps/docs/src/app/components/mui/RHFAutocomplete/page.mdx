# RHFAutocomplete

<AvailabilityBanner componentName="RHFAutocomplete" version="2.0" />

**RHFAutocomplete** extends [Autocomplete](https://mui.com/material-ui/react-autocomplete/)
and is designed for searching and selecting options from large datasets. Similar to
[RHFSelect](/components/mui/RHFSelect), it supports selecting single or multiple options and
accepts options as an array of strings or an array of objects. This component is ideal
for use cases that require dynamic filtering or large option lists.

<Callout type="note">
Starting with **v4**, the `freeSolo` prop is supported in **RHFAutocomplete**, allowing users to enter
values that are not present in the provided options.

When using `freeSolo` with object-based options, custom renderers such as `renderValue`, `renderTags`,
or `renderOptionLabel` should account for both option objects and user-entered string values. A common
approach is:

```ts
typeof value === 'string'
```
to distinguish free-form input from predefined option objects.
</Callout>

## Usage

```tsx
import RHFAutocomplete, { RHFAutocompleteProps } from '@nish1896/rhf-mui-components/mui/autocomplete';
```

```tsx
<RHFAutocomplete
  fieldName="countriesVisited"
  control={control}
  options={['Azerbaijan', 'Canada', 'India']}
/>
```

For options as an array of objects:

```tsx
<RHFAutocomplete
  fieldName="countriesVisited"
  control={control}
  options={countryList} // imported from RHFCountrySelect
  labelKey="name"
  valueKey="name"
/>
```

<Callout type="warning">
When using an array of objects for options, both `labelKey` and `valueKey`
are required. If either is missing, an error will be thrown.
</Callout>
