# MUIRating

`MUIRating` wraps the Material UI [Rating](https://mui.com/material-ui/react-rating/) star input.
The value is a number (or `null` when cleared).

## Usage

```tsx
import MUIRating, { MUIRatingProps } from '@nish1896/mui-components/mui/rating';
```

```tsx
const [score, setScore] = useState<number | null>(null);

<MUIRating
  fieldName="score"
  value={score}
  onValueChange={({ newValue }) => setScore(newValue)}
/>
```

## Props

`MUIRatingProps` also accepts most [RatingProps](https://mui.com/material-ui/api/rating/).
Props marked with <strong style={{ color: 'var(--mui-palette-error-main)' }}>{'*'}</strong> are required.
