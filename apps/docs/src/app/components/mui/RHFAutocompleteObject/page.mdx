# MUIAutocompleteObject

`MUIAutocompleteObject` is an [Autocomplete](https://mui.com/material-ui/react-autocomplete/) that stores the **complete option object** rather than a primitive.

<Callout type="note">
  `freeSolo` is intentionally unsupported to keep the value type predictable — use [MUIAutocomplete](autocomplete)
  or [MUIMultiAutocomplete](multi-autocomplete) instead.
</Callout>

## Usage

```tsx
import MUIAutocompleteObject, {
  MUIAutocompleteObjectProps
} from '@nish1896/mui-components/mui/autocomplete-object';
```

```tsx
const [user, setUser] = useState<User | null>(null);

<MUIAutocompleteObject
  fieldName="user"
  options={users}
  labelKey="name"
  valueKey="id"
  value={user}
  onValueChange={({ newValue }) => setUser(newValue)}
/>
```

## Props
