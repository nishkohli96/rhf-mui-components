# RHFTextField

Text fields are a core component of any form, allowing users to input text into the UI.
The **RHFTextField** component extends the functionality of [TextField](https://mui.com/material-ui/react-text-field/),
accepting almost all TextField props while providing additional customization options.

## Usage

```tsx
import RHFTextField, { RHFTextFieldProps } from '@nish1896/rhf-mui-components/mui/textfield';
```

To render a fully functional `RHFTextField`, you only need two or three essential props.

```tsx
<RHFTextField
  fieldName="firstName"
  control={control}
  customOnChange={({ rhfOnChange, newValue }) => {
    /* Override default onChange to capitalize input text */
    rhfOnChange(newValue.toUpperCase());
  }}
/>
```

You can extend or reuse the `RHFTextField` component by creating your own wrapper component.
