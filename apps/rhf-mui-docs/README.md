# @nish1896/rhf-mui-docs

**The documentation and live-examples site for [`@nish1896/rhf-mui-components`](https://www.npmjs.com/package/@nish1896/rhf-mui-components) — built with Next.js.** 📖

It hosts the setup guides, full props reference, and interactive demos for every component, including complete forms with all the components.

### Documentation

Setup guides, API references, and multiple live variations for every component:

👉 [Documentation Site](https://rhf-mui-components.vercel.app)

### Local Development

From the monorepo root:

```bash
pnpm doc
```

This starts the docs app on [http://localhost:3000](http://localhost:3000). It consumes the built `@nish1896/rhf-mui-components` package, so after changing the library, rebuild it with `pnpm lib`.
