# Introduction

Easily build forms in minutes using the popular [React Hook Form](https://react-hook-form.com/)
library alongside [Material-UI](https://v7.mui.com/material-ui/getting-started/).

This package provides a suite of **20+ reusable and customizable components** specifically
designed to simplify form creation. Each component handles form binding and UI rendering
logic internally, minimizing code duplication and giving developers the flexibility to style form
form fields to match their website's design guidelines.

You can also find additional components in this package, such as **color picker** and **phone input**,
that are not currently part of Material UI but can be useful when you need them. More components will be
added based on community feedback. Feel free to raise a feature request or report a bug by contacting
the author of this package.

## Installation

<Callout type="info" title="Recommended Version">
  For new projects or projects using Material UI `v6` or later, we recommend using
  **v4** of this package. It introduces several new features and enhancements,
  including support for overriding the default `onChange` behavior with `customOnChange`.

  **Version 3 is now in maintenance mode and will only receive bug fixes and compatible
  enhancements. No new features will be added.**
</Callout>

To get started, install the following packages:
- [react-hook-form](https://www.npmjs.com/package/react-hook-form) `v7`
- [@mui/material](https://www.npmjs.com/package/@mui/material) `v7`
- [@mui/icons-material](https://www.npmjs.com/package/@mui/icons-material) `v7`
- [@nish1896/rhf-mui-components](https://www.npmjs.com/package/@nish1896/rhf-mui-components) `v3`

<PackageManagerTabs
  id="install-dependencies"
  command="react-hook-form@^7 @mui/material@^7 @mui/icons-material@^7 @nish1896/rhf-mui-components@^3"
/>

You can refer to the [Material UI installation guide](https://v7.mui.com/material-ui/getting-started/installation/)
for installation instructions.

For date pickers, follow the [installation guide](https://v8.mui.com/x/react-date-pickers/getting-started/)
to install [@mui/x-date-pickers](https://www.npmjs.com/package/@mui/x-date-pickers).

<Callout type="info">
  Still on an earlier **MUI** major? Pick the matching package version from the [table below](#version-compatibility)
  and follow that version's introduction page instead.
</Callout>

**Optional**: If you are using a third party library for form validation, say
[joi](https://www.npmjs.com/package/joi), make sure to install its npm package along
with the [@hookform/resolvers](https://www.npmjs.com/package/@hookform/resolvers) package.

### Usage with Webpack

From **v3 onwards**, this package is **ESM-only**.

If you're using React with Webpack and encounter module resolution errors,
add the following rule to your `webpack.config.js`:

```js
module.exports = {
  module: {
    rules: [
      {
        test: /\.m?js$/,
        resolve: {
          fullySpecified: false
        }
      }
    ]
  }
}
```
