# RHFPasswordInput

**RHFPasswordInput** extends the [TextField](https://v7.mui.com/material-ui/react-text-field/)
component, designed specifically for password input on signup and login pages.
This component allows users to toggle password visibility,
offering a more user-friendly experience when entering credentials.

## Usage

```tsx
import RHFPasswordInput, { RHFPasswordInputProps } from '@nish1896/rhf-mui-components/mui/password-input';
```

`RHFPasswordInput` also requires just 3-4 essential props to render a fully functional field.

```tsx
<RHFPasswordInput
  fieldName="password"
  control={control}
  errorMessage={errors?.password?.message}
/>
```
