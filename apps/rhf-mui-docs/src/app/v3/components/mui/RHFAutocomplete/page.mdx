# RHFAutocomplete

**RHFAutocomplete** extends [Autocomplete](https://v7.mui.com/material-ui/react-autocomplete/),
designed for searching and selecting an option from large datasets. Similar to
[RHFSelect](/v3/components/mui/RHFSelect), it supports selecting single or multiple options and
accepts options as an array of strings or an array of objects. This component is ideal
for use cases requiring dynamic filtering or managing extensive options seamlessly.

<Callout type="note">
  Due to the complexity of supporting arbitrary values in the Autocomplete while ensuring
  existing functionality remains unaffected, this component currently does **not** support
  the `freeSolo` prop of **Autocomplete**. This means users are restricted to selecting
  values exclusively from the dataset provided in the `options` prop, and cannot enter custom
  values.
</Callout>

## Usage

```tsx
import RHFAutocomplete, { RHFAutocompleteProps } from '@nish1896/rhf-mui-components/mui/autocomplete';
```

```tsx
<RHFAutocomplete
  fieldName="countriesVisited"
  control={control}
  options={['Azerbaijan', 'Canada', 'India']}
  errorMessage={errors?.countriesVisited?.message}
/>
```

For options as an array of objects:

```tsx
<RHFAutocomplete
  fieldName="countriesVisited"
  control={control}
  options={countryList} // imported from RHFCountrySelect
  labelKey="name"
  valueKey="name"
  errorMessage={errors?.countriesVisited?.message}
/>
```

<Callout type="warning">
  When using an array of objects for options, both `labelKey` and `valueKey`
  are required. If either is missing, an error will be thrown.
</Callout>
