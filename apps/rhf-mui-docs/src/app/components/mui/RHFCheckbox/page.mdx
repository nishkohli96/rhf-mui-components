# RHFCheckbox

The **RHFCheckbox** component renders a checkbox, allowing users to toggle an option on or off,
such as subscribing to a newsletter. It extends the [Checkbox](https://mui.com/material-ui/react-checkbox/)
component from MUI, accepts most of its props, and offers similar
customization options.

## Usage

```tsx
import RHFCheckbox, { RHFCheckboxProps } from '@nish1896/rhf-mui-components/mui/checkbox';
```

```tsx
<RHFCheckbox
  fieldName="agreeTnC"
  control={control}
  label="Agree to Terms & Conditions"
/>
```
