# Changelog - v5

## [5.0.2](https://github.com/nishkohli96/rhf-mui-components/tree/v5.0.2)

**Released — 28 August, 2026**

### ⚙️ Project & Tooling
- Upgrade `mui-components` to `v2.0.4`.
- Removed `@faker-js/faker` from the docs-website client bundle — demo option data is now precomputed (`airports.json`) or a static list.
- Downscaled oversized image assets (`logo-dark.png` 2.2 MB → ~50 KB, `logo.png`, `404.png`) and deleted unused ones (`rhf-mui.png`, `rhf-mui-logo.png`).
- Replaced the remote `img.icons8.com` header icons with a self-hosted npm SVG and the MUI GitHub icon.

### 📖 Docs — SEO
- Added `metadataBase`, a per-route self-referencing `canonical`, `og:url`, Open Graph / Twitter Card tags, and a build-time 1200×630 `opengraph-image` on every page.
- Added structured data — `WebSite` + `Person` site-wide, `SoftwareSourceCode` on the home page, `BreadcrumbList` on every docs page.
- Added `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, `apple-icon`, and a generated `/llms.txt`.
- Older doc versions (`/v1`–`/v4`) are now `noindex` and show a banner linking to the latest version.
- Home page: descriptive `<title>`, an `h1`/`h2` outline, and grouped deep-link sections (live examples, popular components, setup) for internal linking.
- Component page `<h1>`s now match their page titles; expanded several thin component meta descriptions.
- Anchored headings no longer leak a literal `#` into their text content.
- Added `priority` + `sizes` to the above-the-fold header logo image.

### 🐞 Bug Fixes
- Sidebar: removed `unmountOnExit` from the mobile/desktop nav `Collapse` — collapsed sections were dropping their links entirely from the server-rendered HTML, leaving every page outside the one auto-expanded section unreachable without JS.
- `RHFFileUploader`: Fixed single-file mode wiping the current value to `null` when a replacement file was rejected (invalid type/size or over `maxFiles`) — the current file is now kept instead.
- Fixed `componentMetadata` page titles for all components in the docs website — several still read `MUI*` instead of `RHF*`.
- Replaced the unmaintained `react-json-view` with `@microlink/react-json-view`; the old package fails to instantiate under React 19 + Turbopack (*"module factory is not available"*).

## [5.0.0](https://github.com/nishkohli96/rhf-mui-components/tree/v5.0.0)

**Released — 12 August, 2026**

### ⚙️ Project & Tooling
- Upgrade **pnpm** from `11.8.0` to `11.10.0`
- Removed the **Docusaurus-based** Docs app and the standalone **Next.js** Examples website.

### 💥 Breaking Changes
- Added compatibility with **MUI** and **MUI X-Pickers** `v9`.
- Upgrade `mui-components` to `v2.0.2`.
- Remove the *deprecated* `errorMessage` prop from all components.

### ✨ Enhancements
- Added component-level JSDoc summaries (with links to docs and API reference) to every `RHF*` component across the `mui`, `mui-pickers` and `misc` modules.
- Added JSDoc comments for `fieldNameToId`, `getFileSize` and `validateFileList` functions, exported from the `form-helpers` module.

### 📖 Docs
- Launched a new documentation website built with **Next.js** and **MDX**, now featuring comprehensive form examples alongside the component documentation.
- Added `logo-dark` to improve icon visibility and make the logo details more prominent in the dark theme.

### 🐞 Bug Fixes
- `getFileSize`: Fixed trailing zeros (e.g. `1.20`) not being stripped from the decimal part.
- `validateFileList`: Fixed `maxSize={0}` and `maxFiles={0}` being treated as "no limit" instead of rejecting all files.
